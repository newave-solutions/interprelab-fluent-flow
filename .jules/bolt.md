## 2024-10-12 - Consolidating Array Traversals for O(N) Complexity
**Learning:** React components that calculate multiple aggregate statistics across lists of data (like `CallTracker.tsx` and `Dashboard.tsx`) often accumulate technical debt through multiple chained O(N) array functions (e.g., up to 10 back-to-back calls to `.reduce()` and `.filter()`).
**Action:** When discovering chained `reduce()`/`filter()`/`map()` traversals on arrays that are used to compute disparate scalar values, consolidate them into a single `for...of` loop. This avoids multiple intermediate array allocations and bounds checks, providing O(1) loop overhead and significantly improving layout render performance during frequent component updates.
