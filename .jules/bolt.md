## 2025-02-28 - InterpreSigns component derived state and calculation optimization
**Learning:** Multiple consecutive `.filter()` and inline `.reduce()` operations on arrays (especially derived directly from state objects like `Object.values(state).reduce()`) cause continuous creation of intermediate arrays and O(N) operations on every re-render. Additionally, storing derived aggregations (like `totalMastered`) in state and synchronizing them within `useEffect` or other state-setter callbacks introduces redundant state updates and synchronization complexity.
**Action:** Replace separate state trackers and chained array methods for derived aggregations with a single `React.useMemo` block that uses a fast `for...in` or `for...of` loop to compute all aggregates in one O(N) pass, directly referencing the primary state.
