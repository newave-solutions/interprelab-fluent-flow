## 2026-10-03 - Accessible Icon-only buttons\n**Learning:** The project relies heavily on Shadcn UI Tooltips and aria-labels for accessible icon-only buttons. The global TooltipProvider means components only need to import Tooltip, TooltipTrigger, and TooltipContent.\n**Action:** When adding new icon-only controls, always wrap them in Tooltip components and provide descriptive aria-labels and focus-visible outlines.
