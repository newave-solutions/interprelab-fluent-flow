## 2024-03-24 - Accessibility for Icon Buttons with Numbers
**Learning:** When making buttons accessible that contain an icon alongside a visual numeric count (e.g., `<button><Heart/> <span>0</span></button>`), adding `aria-hidden="true"` to the numeric span prevents screen readers from announcing the actual number. The correct pattern is to wrap the description in a visually hidden span (`<span className="sr-only">Like post, count:</span>`) and leave the numeric span visible to both sighted users and screen readers (without `aria-hidden`). The icon itself should still receive `aria-hidden="true"`.
**Action:** When implementing accessible buttons with dynamic text/numbers, ensure only decorative icons and redundant labels receive `aria-hidden="true"`. The dynamic content must remain accessible.
