## 2025-02-27 - DOM-based XSS in Chrome Extension Content Script
**Vulnerability:** The Chrome extension content script (`public/chrome-extension/content-script.js`) injected dynamic user input (such as transcription text, PII extraction matches, and API feedback) directly into the DOM using `.innerHTML` without any sanitization.
**Learning:** Because this script operates outside the main React application context, it does not benefit from React's built-in XSS protections or libraries like `DOMPurify` that are part of the web app bundle. Native vanilla JS elements assigned via `.innerHTML` remain vulnerable.
**Prevention:** Always implement and use a custom `escapeHTML` helper function in vanilla JS contexts when dynamically assembling HTML strings that include untrusted or external data before assigning to `.innerHTML`, or use safer alternatives like `.textContent` where possible.
